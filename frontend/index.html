How It Works

Five layers of technology working together

01

Upload

Doctor uploads a chest X-ray image through the web interface

02

AI Analysis

MobileNetV2 model classifies the image as Normal or Pneumonia

03

Explainable AI

Grad-CAM generates a heatmap showing which lung regions influenced the diagnosis

04

Encrypt & Hash

Image is encrypted with AES-256 and fingerprinted with SHA-256

05

Blockchain

CID and hash are permanently recorded on Ethereum smart contract

Technology Stack

Built with industry-standard tools for reliability and security

TensorFlow

Deep learning framework powering the MobileNetV2 model

Grad-CAM

Gradient-weighted Class Activation Mapping for visual explanations

AES-256 / SHA-256

Military-grade encryption and tamper-proof hashing

IPFS

InterPlanetary File System for decentralized image storage

Ethereum

Smart contracts on Ganache for immutable medical records

Python + FastAPI

Backend API serving the AI model and processing pipeline
